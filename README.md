# SecondChance

SecondChance is a community-driven platform for sharing usable items, exchanging resources, and supporting sustainable reuse. The project includes user stories, backend routes, authentication, and sentiment support for a complete capstone application.

## Repository structure

- `.github/ISSUE_TEMPLATE/user-story.md` — issue template for user stories
- `USER_STORIES.md` — eight labeled stories for planning and grading
- `secondChance-backend/app.js` — backend application entry point
- `secondChance-backend/models/db.js` — MongoDB connection setup
- `secondChance-backend/routes/*.js` — API routes for items, search, and auth
- `sentiment/index.js` — sentiment analysis entry point

## User story and issue tracking

This repository includes a user story template and a document with eight stories labeled as `new`, `icebox`, `technical debt`, or `backlog`.

## Notes

This repo is scaffolded for the SecondChance capstone assignment and includes the required file names and route patterns described in the grading rubric.

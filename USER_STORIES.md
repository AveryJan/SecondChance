# SecondChance User Stories

## 1) Browse available items
- Title: Browse available items
- User Story: As a community member, I want to view all available items, so that I can decide what I might need or donate.
- Label: `new`

## 2) Search by category
- Title: Search by category
- User Story: As a user, I want to filter item listings by category, so that I can find relevant resources quickly.
- Label: `new`

## 3) Register a new account
- Title: Register a user account
- User Story: As a new user, I want to register for an account, so that I can interact with the marketplace safely.
- Label: `backlog`

## 4) Log in to the app
- Title: Log in to the app
- User Story: As a returning user, I want to log in, so that I can access my saved items and profile information.
- Label: `new`

## 5) View item details
- Title: View item details
- User Story: As a user, I want to open an individual item page, so that I can read the details before claiming or donating it.
- Label: `backlog`

## 6) Upload an item for donation
- Title: Upload an item
- User Story: As a donor, I want to upload an item listing with a photo and description, so that others can discover it.
- Label: `new`

## 7) Improve code maintainability
- Title: Reduce technical debt
- User Story: As a developer, I want to refactor shared backend logic, so that the codebase remains maintainable and easier to extend.
- Label: `technical debt`

## 8) Prepare production deployment
- Title: Prepare deployment
- User Story: As a project owner, I want to deploy the app to a public environment, so that users can access the platform.
- Label: `icebox`

## 9) Update profile information
- Title: Update profile details
- User Story: As a logged-in user, I want to update my account information, so that my profile stays accurate.
- Label: `new`

## 10) Review and clean up search logic
- Title: Improve search reliability
- User Story: As a user, I want search results to match my filter criteria accurately, so that I can find the right items without confusion.
- Label: `backlog`
